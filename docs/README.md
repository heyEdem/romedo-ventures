# Romedo Ventures Prototype Documentation

This documentation turns [`prototype/docs/prototype-prd.md`](../prototype/docs/prototype-prd.md) into an implementation backlog for the mobile-first digital catalogue prototype.

## Documents

- [Five Questions](five-questions.md): extracted outcomes, invariants, ownership, tests, and exclusions.
- [Task Index](taskindex.md): progress tracker and source map for every phase and task.
- [ADRs](adrs/): architecture and product-boundary decisions.
- [Implementation Plans](implementation-plans/): phase-level plans for AI-assisted implementation.
- [Epics](epics/): phase folders containing individually executable tasks.

## Scope guardrails

This is a catalogue and enquiry storefront. It does not include carts, checkout, payments, orders, accounts, delivery tracking, inventory quantities, reviews, recommendations, loyalty, or complex analytics.
